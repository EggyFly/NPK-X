# 字段贴图插件

浏览器顶部点击 **字段贴图**，即可管理显示在名称前的小图标。

## 使用方法

1. 选择作用位置：全部位置、字段键名、资源对象或 GMP 组件。
2. 选择精确匹配或包含文字，填写目标名称。匹配不区分大小写。
3. 填写当前资源库的贴图路径（例如 `gui2/main/img_spawn_qipao.kta`），或上传 PNG、JPG、WebP、GIF 图片。
4. 选择 16、20、24 或 32 px，点击 **添加规则**。已经打开的详情和地图会立即刷新图标。

资源对象支持按 `Name`、对象索引或可用的 `Class`、`Type` 匹配。展开 GIM/MTG 详情中的对象行，可以查看完整字段及其贴图。GMP 支持按组件显示名称、组件 ID、eid 或模型路径匹配，作用于预览列表和地图图例。规则从上到下匹配，仅显示第一条启用规则的贴图。

## 保存与迁移

- 配置自动保存在当前浏览器的本地存储，刷新后保留；不同浏览器或端口使用独立配置。
- **导出配置**会生成 `npk-field-icons.json`，包含上传图片；**导入配置**追加规则，保留已有设置。
- 每条规则可以编辑、停用和删除；顶部开关可一次关闭或恢复全部贴图。
- 上传图不发送到服务器，会转换为最长边 128 px 的静态 PNG，保留透明背景。GIF 使用解码时的静态画面。
- 最多 200 条规则；单张上传图片最多 8 MB，缩小后的配置总量最多约 3.5 MB。

插件只改变标签外观，不修改源资源、模型材质或 3D 渲染参数。仅接受本地上传图片和当前资源库路径，不接受远程网页地址或可执行代码。
